# ConflictMediator (갈등 중재 앱)

대화 중 갈등을 건설적으로 해결하도록 돕는 iOS 앱입니다.

## 시작하기

### 요구사항
- Xcode 15.0 이상
- iOS 17.0 이상
- macOS Monterey 이상

### 설치 방법

1. `ConflictMediator.xcodeproj` 파일을 더블클릭하여 Xcode에서 엽니다
2. 상단에서 타겟 디바이스를 선택합니다 (시뮬레이터 또는 실제 기기)
3. `Command + R`을 눌러 빌드하고 실행합니다

## 주요 기능

### 1. 대화 타이머
- 각 사람의 발화 시간을 실시간으로 추적
- 발화량 균형을 시각적 바로 표시
- 2분마다 턴 전환 제안 (햅틱 피드백)
- 일시정지/재개/초기화 기능

### 2. 입장 차이 시각화
- 주제별 입장을 슬라이더로 표현 (0-100%)
- 양측 입장을 나란히 비교
- 입장 차이를 백분율로 계산

### 3. 합의 사항 기록
- 대화 중 합의한 내용 기록
- 양측 모두 확인해야 최종 합의
- 시간 기록과 함께 저장

### 4. 중재 프롬프트
- 8가지 건설적인 대화 가이드
- 적극적 경청, I-Message 사용 등의 실용적 팁
- 발화량 차이가 클 때 자동 중재 제안

## 사용 방법

1. **대화 타이머 탭**
   - "사람 A" 또는 "사람 B" 카드를 탭하여 발화 시작
   - 발화량 균형을 실시간으로 확인
   - 필요시 일시정지 또는 초기화

2. **입장 차이 탭**
   - 우측 상단 + 버튼으로 새 주제 추가
   - 각자의 입장을 슬라이더로 설정
   - 입장 차이를 시각적으로 확인

3. **합의 사항 탭**
   - + 버튼으로 합의 내용 기록
   - 각자 확인 버튼을 눌러 최종 확인

4. **중재 도움말 탭**
   - 건설적인 대화를 위한 팁 확인
   - 중재 프롬프트 참고
